# Changelog

All notable changes to the **Cha Thai** extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- **Cha Thai Dark**: A brand-new dark theme variant with deep charcoal brown backgrounds and elegant Thai tea accents.
- Professional UI elements matching both light and dark environments.

### Changed
- **Cha Thai (Light)**: Completely refined the color palette. Replaced overly saturated oranges and harsh browns with muted, ergonomic tones (Terracotta, Muted Cocoa, Soft Sand) to reduce eye strain and improve the professional aesthetic.
- Updated documentation (README, CHANGELOG, etc.) for better readability and a more professional presentation.

## [0.0.3] - Initial Release

### Added
- Initial release of the Cha Thai light theme.
- Basic syntax highlighting for major programming languages.
- Custom workspace UI colors.
