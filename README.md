**Cha Thai** is a professional, elegant, and vibrant Visual Studio Code theme family inspired by traditional Thai milk tea. Designed with long coding sessions in mind, it provides a warm and comfortable visual experience without compromising on syntax clarity.

The theme now includes both **Light** and **Dark** variants to suit your environment and preferences.

---

## ✨ Features

- 🌿 **Ergonomic & Professional** — Muted, desaturated color palettes designed to reduce eye strain during extended use.
- 🧋 **Dual Themes** — Includes **Cha Thai** (Light) for daytime focus and **Cha Thai Dark** for low-light environments.
- 🎯 **Syntax Clarity** — Carefully tuned token colors across all major programming languages.
- 🎨 **UI Harmony** — Consistent, minimal, and elegant accent colors across the sidebar, tabs, and status bar.

---

## 🖌️ Theme Variants

### ☀️ Cha Thai (Light)
A soft, warm cream background paired with muted terracotta and cocoa accents. It brings the refreshing vibe of Thai tea into a clean, professional workspace.

### 🌙 Cha Thai Dark
A deep, rich charcoal brown background that makes the Thai tea orange accents pop beautifully. Perfect for developers who prefer a sleek, dark aesthetic.

---

## 🚀 Installation

1. Open **VS Code**
2. Go to **Extensions** (`Ctrl+Shift+X` or `⇧⌘X` on macOS)
3. Search for **Cha Thai**
4. Click **Install**
5. Open the **Command Palette** (`Ctrl+Shift+P` or `⇧⌘P`), type `Preferences: Color Theme`, and select either **Cha Thai** or **Cha Thai Dark**.

## 🧑‍💻 Development

- Open the repository in VS Code and press `F5` to launch the Extension Development Host.
- Edit `themes/cha-thai-color-theme.json` or `themes/cha-thai-dark-color-theme.json`.
- Reload the Development Host window to see changes instantly.
